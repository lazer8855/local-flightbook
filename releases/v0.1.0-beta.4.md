# Flightbook v0.1.0-beta.4

This beta makes XC calculation explicit and reusable, adds linked flight analysis, and expands every statistics card to fill the window. Download the new `dashboard.html`; existing map files remain compatible.

## What's new

- **Highest-scoring XC route:** distances in lists, filters, statistics, records and map overlays now use the route earning the most points under the pinned Swiss CCC 2026 geometry rules. Candidates are open distance, straight distance, flat triangle and FAI triangle. A shorter triangle can win over a longer open route. These are local estimates, not official contest scores or eligibility checks; the same rules apply to every recorded year.
- **Calculate when you choose:** importing or rescanning no longer starts expensive XC searches. Use **Calculate missing XC scores**, watch progress, and cancel when needed. **Refine estimated scores** gives unfinished searches more time while preserving better existing candidates. Results remain approximate until all candidate searches have proved their optimum.
- **Portable XC database:** completed results save in batches to `flightbook-xc.json` in the selected flight folder. Grant folder write access when calculation starts. Content hashes reuse results for unchanged files, including renamed/moved files and identical copies. Only missing or incompatible results need calculation. Completed work survives cancellation; failed saves retain results for retry. Invalid or externally changed databases are protected from overwrite.
- **Consistent manual distances:** optional manual open-route distances remain included throughout the dashboard and clearly labelled as manual; no contest points or triangles are invented. Missing distances remain unknown while calculated totals and coverage update.
- **Linked flight analysis:** inspect GPS/barometric altitude and an optional local terrain profile beneath the map. Hover, drag, use the time slider, or select a position on the map to link the profile and track cursor. Read recorded UTC time, speed, climb/sink, ground elevation and approximate height above ground. Recording gaps remain visible. Pilot, glider registration and first/last recorded-fix times appear when available.
- **Scored-route overlay:** show the winning route's start, finish, turnpoints and leg distances on the track; triangle overlays also show the closing gap. The overlay can be toggled independently.
- **Expandable statistics:** every statistics card opens in a full-window view with Escape to close. Normal annual activity cards show up to ten years before scrolling; expanded charts fit all years, switching to horizontal bars when needed. Values appear inside the bars with orientation matching the layout.

## Start or upgrade

1. Download `dashboard.html` from this release and replace your older dashboard.
2. Open it directly in desktop Chrome or Edge. No server, installation, account or API key is needed.
3. Choose your flight folder and existing background/optional terrain PMTiles files. Everything works offline after download.
4. Click **Calculate missing XC scores** when ready and approve folder write access. Reopening the same archive loads saved results without starting calculation. Keep `flightbook-xc.json` with your flights when moving or backing them up.

IGC files are never modified. Existing version-1 manual JSON and saved Review decisions remain compatible. Old browser-only XC results may need one explicit calculation to populate the new portable database. XC distance values can change because the dashboard now uses the highest-scoring route rather than always using open distance. Manual-distance fields keep their existing schema.

## Validation and limitations

All **59 unit tests pass**, including the supplied 431 IGC files, scoring selection, content-hash caching, persistence, shared filtering, comparisons and manual distances. Offline Chrome and Edge checks passed during implementation for XC calculation/database workflows, linked profiles, statistics cards, shared statistics and Review. Native folder write permission, database saving and reopening were also verified in both browsers using isolated test folders. These browser checks reported no HTTP requests or console errors.

XC searches can take time, especially triangle refinement; time-limited results remain estimates. Swiss geometry multipliers are straight/flat triangle ×1.2, FAI triangle ×1.4 and open ×1.0; other contest rules and historical rule sets are not implemented. Flights below the CCC final-ranking minimum remain visible locally. See the [official Swiss CCC 2026 rules](https://www.shv-fsvl.ch/fileadmin/files/redakteure/Allgemein/Sport/Reglemente/2026/Reglement_D_2026.pdf).

Recorded airtime spans the first and last valid fixes and may include gaps or time on the ground. Terrain and approximate height above ground depend on archive detail, GPS accuracy and vertical datums; they are not clearance measurements. Manual entries have no GPS profile. Flight playback is not included.
