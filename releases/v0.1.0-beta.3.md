# Flightbook v0.1.0-beta.3

This beta adds a Review view for duplicates and questionable recordings, plus configurable GPS-warning thresholds. Download the new `dashboard.html`; existing map files from beta 2 remain compatible and do not need downloading again.

## What's new

- **Review tab:** inspect exact file duplicates, repeated manual-flight IDs, similar IGC recordings, manual/IGC matches, short recordings, suspicious data and import failures.
- **Manual/IGC matching:** manual flights now accept an optional local start time. Its UTC instant is stored to compare with IGC timestamps correctly, including dates around midnight. Start-time tolerance defaults to five minutes. Entries without a start time can produce lower-confidence date/duration suggestions.
- **Reversible decisions:** ignore warnings, exclude/include flights, or choose which entry in a matching group counts. Exclusions apply immediately to Flightbook, statistics, comparisons, all-track overlays and heatmaps. Excluded flights can still be opened for individual preview.
- **Portable review settings:** click **Save decisions** to write `flightbook-review.json` in the selected flight folder. Approve write access if requested. Decisions and thresholds load again when reconnecting the folder. Original IGC and manual JSON files remain untouched by review actions.
- **Invalid GPS allowance:** the default is **15 invalid fixes**. Recordings are flagged for this reason only when they exceed that count. Adjust **Allowed invalid GPS fixes** in Review and save decisions to remember it. Existing saved custom values take precedence.
- **Fewer noisy warnings:** repeated timestamps are silently skipped; GPS jumps no longer trigger Review warnings. Truly out-of-order timestamps, malformed records, insufficient fixes, missing dates and gaps longer than ten minutes can still be flagged.

Exact duplicates are now retained for review instead of being silently skipped. **All imported entries count until you explicitly exclude them.** Review checks the full archive independently of Flightbook filters. Ignoring a warning does not exclude a flight, and no records are deleted or merged. Manual notes stay on the original entry.

## Start or upgrade

1. Download this release's `dashboard.html`, replacing your older dashboard.
2. Open it directly in desktop Chrome or Edge; no server, installation, API key or account is needed.
3. Choose your flight folder and grant read access. Choose your existing background and optional terrain PMTiles files.
4. Open **Review**, inspect suggestions and save decisions when ready. The browser may request folder write permission. Using the downloaded files works offline.

Old manual version-1 files remain compatible. Review identities use relative paths plus content hashes for IGC files, or manual IDs; renamed/moved files need reviewing again. Unsaved decisions survive rescans and failed saves. Invalid review files and externally changed decisions are protected from overwrite.

## Validation and limitations

All **49 tests pass**, including scanning the supplied 431 IGC files, configurable allowance boundaries, saved custom thresholds and older review-file compatibility. Offline Chrome and Edge Review checks pass, including local maps/heatmaps, saving/reopening decisions, permission denial/retry, write failures, external-change protection, manual start-time editing and responsive layouts. The browser checks report no HTTP requests or console errors. Native folder/review-file write workflows were also verified during Review implementation using isolated scratch files.

Review findings are suggestions, not proof that a recording is broken or duplicated. Nearby pilots can produce similar tracks; compare entries before excluding one. Invalid fixes remain skipped during parsing; raw invalid-fix counts remain available in recording notes. Recorded duration still spans the first and last valid fixes and can include gaps or time on the ground. XC estimates are not official contest scores.
