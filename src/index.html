Connect your files

  1. Use desktop Chrome or Edge and click Choose flight folder.
  2. Select the main folder containing your flights and approve read access. Every subfolder is scanned, whatever its name.
  3. Click Choose map and select switzerland.pmtiles, world.pmtiles, or europe.pmtiles.
  4. For a manual flight, choose its save location and approve write access if asked.

Repeat these selections after reopening. Your IGC files are never changed.

Flight review

Review checks the full archive, independently of Flightbook filters. Nothing is excluded automatically. Exclusions affect Flightbook, statistics and map overviews immediately; opening an excluded flight previews it individually.

Save decisions writes only flightbook-review.json in your selected flight folder. Approve write access when asked. Original IGC and manual-flight files are never changed by review actions. Ignoring a warning does not exclude a flight. Decisions follow the file path and content hash (or manual ID); renamed or moved files need reviewing again.

About XC distances

Open XC optimizes start, up to three turnpoints and finish. ≈ marks a time-limited estimate. Manual distances are entered by you. Triangle results remain available in flight details. These are local estimates, not official contest scores.
